# MX1

هذه هي نسخة Worker الخاصة بواجهة MX1. الواجهة العامة تعمل على `https://mx1.elazzouz4.workers.dev`، بينما تتصل قاعدة D1 داخليًا عبر binding باسم `D` ولا يظهر عنوان قاعدة البيانات للمستخدم.

## النشر التلقائي

يعمل سير النشر عند دفع تغييرات إلى مجلد `mx1/` في الفرع `main`. يحتاج مستودع GitHub إلى Secret واحد باسم `CLOUDFLARE_API_TOKEN` بصلاحيات نشر Workers وقراءة/استخدام D1. لا تضع هذا المفتاح في ملفات المشروع أو في الواجهة.

معرّف حساب Cloudflare موجود في workflow لأنه ليس سرًا. بعد إضافة Secret، يؤدي أي push إلى `mx1/**` إلى نشر Worker باسم `mx1`.
